# Gameplay background library

Put your authorised Minecraft parkour clips in the `gameplay` subfolder:

```
assets/
  README.md
  gameplay/
    parkour_000.mp4
    parkour_001.mp4
    parkour_002.mp4
    ...
```

The renderer randomly selects one `parkour_*.mp4` clip for each generated story video. If no clips are present in this folder, it falls back to `assets/minecraft_parkour.mp4`, then to the optional `BACKGROUND_URL` repository variable.

Candidate source: OrbitalNCG — https://www.youtube.com/watch?v=u7kdVe8q5zs

The creator's description supplied for BYTEFORGE says the gameplay may be reused and monetised with credit, but may not be re-uploaded as a standalone no-copyright gameplay video. The creator's best-quality download page is https://ko-fi.com/s/0a60cae8c9. Check the current terms and any price there before obtaining the file.

The video generator uses only the visual track; it discards the source audio and adds BYTEFORGE narration. Verify the creator's current reuse terms and provide required attribution before publishing.
